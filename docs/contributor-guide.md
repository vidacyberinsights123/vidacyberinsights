# Contributor Guide

## Branching Model
- `main`: Production-ready code.
- `chore/*`: Configuration/Maintenance.
- `feat/*`: New features.
- `fix/*`: Bug fixes.
- `content/*`: Content updates.

## Pull Requests
- Must pass all automated checks.
- Require 1 approval.

## Commit Messages
Use Conventional Commits:
- `feat: add new article blueprint`
- `fix: typo in glossary`
